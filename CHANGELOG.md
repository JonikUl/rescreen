# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

Правило релизов: версия в `package.json` и секция в этом файле поднимаются в том же PR, который мержится в `master` (см. «Релизный процесс» в README).

## [0.1.0] - 2026-10-15

### Добавлено

- Команды CLI: `init` (конфиг с примером и `.rescreen/`), `run [page...]` (снятие Snapshot'ов, сравнение с Baseline'ами, фильтрация по Page), `approve [page...]` (подтверждение Diff'ов с записью в Audit Log), `status` (доска актуального состояния всех Page), `prune [--dry-run]` (уборка устаревших Snapshot'ов вне конфига), `open` (открытие последнего Report'а в браузере).
- Типизированный конфиг `rescreen.config.ts` (`defineConfig`) с валидацией и понятными ошибками до старта Run'а.
- Стабилизация снимков из коробки: ожидание network idle, отключение CSS-анимаций, маскирование селекторов с пометкой штриховкой, ожидание стабильного кадра для JS-анимаций.
- Элементные Snapshot'ы по CSS-селекторам со своими Baseline'ами и Diff'ами.
- Порог расхождения (по умолчанию 0) глобально и per-page; viewport'ы по умолчанию и per-page; full-page снимки.
- Самодостаточный HTML Report на русском: резюме человеческим языком, группировка «изменились / без изменений / новые», сравнение «было/стало» и Diff-изображения с подсветкой.
- Approve по неподтверждённым Diff'ам из хранилища, а не по последнему Run'у (ADR-0003): частичный Approve и пересъёмка оставшихся Page.
- Хранилище `.rescreen/` за интерфейсом `BaselineStorage`: Baseline'ы, текущие Snapshot'ы, Diff'ы, Audit Log (JSONL с sha256), per-key состояние для доски Status (ADR-0004).
