# TypeScript + Playwright, а не Rust

**Status:** accepted

Выбираем язык и движок для rescreen. Решение: чистый TypeScript + Playwright (headless Chromium) для снятия Snapshot'ов; diff-движок прячется за интерфейсом (первый — pixelmatch), чтобы его можно было заменить на нативный (odiff) без переписывания ядра.

Рассматривался Rust (или связка TS+Rust) ради скорости diff'а. Отклонён: узкое место инструмента — рендеринг в браузере (секунды на Page), а не сравнение PNG (миллисекунды); выигрыш Rust лежал бы в пределах погрешности, а налог на скорость итераций для соло-разработчика — реален. Нативную скорость diff'а при необходимости даст готовый бинарник odiff, вызываемый из CLI.

## Consequences

- Весь код — TypeScript; контрибьюторы из frontend-сообщества могут участвовать без знания Rust.
- Если профилирование покажет, что diff стал узким местом, замена движка — локальное изменение за интерфейсом, а не миграция.
